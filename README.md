# 와이플랜 Y-PLAN

온라인 마케팅 회사 와이플랜의 마케팅 홈페이지입니다. Next.js 16.4, React 19 기반이며 Vercel로 배포합니다.

## 구성

- 오렌지·블랙 색상, 큰 타이포그래피, 반응형 화면
- 메인 홈페이지, 별도 회사소개 페이지, 서비스 전체 목록, 15개 서비스 상세 페이지
- 진행 과정, FAQ, 상담 폼
- 상세 페이지의 상담 버튼으로 이동 시 해당 서비스 자동 선택
- 키보드 접근, 모바일 메뉴, 개인정보 안내 대화상자
- 현재 연결 전 상담 방식: 작성한 내용을 `ysh01110@naver.com`으로 보내는 메일 앱 열기. 사용자가 메일 앱에서 전송해야 합니다.
- Supabase 연결 후: 서버 검증, 중복 방지, 시간당 접수 제한, 상담 저장
- Resend 연결 후: 담당자 이메일 알림. 메일 오류가 발생해도 데이터베이스에 상담을 보관합니다.

## 온라인 접수 연결

1. Supabase 프로젝트에서 `supabase/schema.sql`을 적용합니다.
2. Vercel 프로젝트 설정의 환경 변수에 `.env.example`에 표시한 값을 등록합니다.
3. `SUPABASE_SERVICE_ROLE_KEY`는 서버 전용입니다. `NEXT_PUBLIC_` 접두사를 붙이거나 브라우저 코드에 포함하지 마세요.
4. `CONSULTATION_HASH_SECRET`은 임의의 충분히 긴 비밀 값으로 설정합니다.
5. Resend에서 발신 도메인을 인증하고 `RESEND_API_KEY`와 `CONSULTATION_FROM_EMAIL`을 설정합니다. 수신자는 `CONSULTATION_TO_EMAIL`이며 기본값은 지정하신 네이버 주소입니다.
6. 환경 변수 설정 후 Vercel에서 재배포합니다.

데이터베이스 설정이 없으면 이메일 상담 모드로 동작하며, 자동 접수 완료를 표시하지 않습니다. 데이터베이스가 연결되어 있고 발송 서비스만 연결되지 않은 경우 상담은 저장되지만 이메일 알림은 보내지 않습니다.
